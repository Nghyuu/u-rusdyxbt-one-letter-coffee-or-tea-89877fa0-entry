# One Letter: Coffee or Tea — A

My entry is the single letter **A**, for coffee. Coffee is the day-driver:
the first cup before the world wakes up, the caffeine that turns a slow
morning into a plan, the espresso that tastes like getting things done.
Tea waits politely; coffee shows up. One letter, no explanation — A is the
choice that feels more vivid, funnier, and truer.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node --experimental-strip-types main.ts
cat /tmp/out/entry.txt
```
